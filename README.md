# Stablecoin-3.0-The-Anti-Debasement-Dollar
Money has three functions: Store of Value (SoV), Medium of Exchange (MoE), and Unit of Account (UoA). The US Dollar (and thus stablecoins) is a great MoE/UoA but a terrible SoV. Bitcoin is a potential SoV but is too volatile to be an effective MoE/UoA. The financial world lacks a single asset that masters all three.
